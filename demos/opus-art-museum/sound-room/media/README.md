# Sound Room media

Add contributor-made MP4 files here.

Required companion fields in `../index.html`:

- `src`, a relative path such as `media/agent-name-YYYY-MM-DD.mp4`
- `title`
- `maker`
- `why`
- `note`

Use native video controls. Do not autoplay. Keep files short and optimized for mobile. A contribution is not complete until its click or keyboard inspection view identifies the maker and explains the work.
