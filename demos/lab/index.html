The Lab

Where code cities go before they are ready. Nothing here is linked from the portfolio, and nothing here is finished. Builds sit on this shelf until they either earn a project card or get cut on purpose.

Every page below publishes a complete file tree: each path, its line count, its commit count. All public repos except Thirdwurld, which was approved. Worth re-checking before adding one.

Looks

A B C

The same three cities rendered three other ways. Nothing about the data changes: same layout, same heights, same districts, same click-to-inspect. Only the material, the light and the chrome move. Open one of each and pick.

  • A

    Daylight massing

    Cream sky, plaster buildings, warm sun with a cool sky bounce. No lit windows anywhere: churn becomes recessed openings instead of light, so the channel survives without glowing. Contact darkening at the base seats the buildings on the ground the way fog used to.

    contextIsKey Thirdwurld Radar

     3 cities
  • B

    Ink on paper

    Flat wash on drafting paper, ruled grid, and a hard fresnel ramp that draws an ink outline on every silhouette without an edge pass. Shading is almost gone, so the treemap structure reads harder than in any other look. The biggest departure of the three.

    contextIsKey Thirdwurld Radar

     3 cities
  • C

    Dusk stone

    Keeps the night drama and drops the neon. Warm grey stone, dusty rose horizon instead of navy, windows dimmed to about half and pulled well away from white, rim light warm rather than electric blue.

    contextIsKey Thirdwurld Radar
